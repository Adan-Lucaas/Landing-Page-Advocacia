# 🏛️ Landing Page - Escritório de Advocacia

Uma interface institucional elegante voltada para advogados, destacando especialidades e facilitando o agendamento de consultas.

## 🚀 Tecnologias
* **HTML5 Semântico**: Melhor indexação em motores de busca (SEO).
* **CSS3 Avançado**: Uso de Flexbox e Grid para garantir que o site funcione em qualquer celular.
* **WhatsApp Integration**: Botão flutuante para contato imediato.
